# Does Length Buy Quality? Runtime and Audience Reception in TMDb Film Data, 2000–2024

An R analysis investigating whether a movie's runtime affects its audience reception, using TMDb film data from 2000 to 2024. This project was completed as part of my MSc coursework and scored 96/100.

## Project Structure
- `01_load_data.R` — script to load and merge movie data
- `data/` — raw TMDb dataset (CSVs by year)
- `reports/` — analysis report outputs
- `MAS8505_runtime_report main.pdf` — final written report
- `Untitled.Rmd` — RMarkdown analysis file

## Tools Used
- R / RStudio
- dplyr, ggplot2 (data wrangling and visualization)
- Statistical modeling (regression analysis)

## Key Question
Does a longer movie runtime correlate with better audience reception (ratings/votes)? This project explores that relationship using over two decades of TMDb film data.
